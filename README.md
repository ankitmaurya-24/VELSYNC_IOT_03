# VELSYNC_IOT_03: Smart Home Automation

## Project Overview
This project is part of my **Velsync Internship (IoT & Embedded Systems)**. 
The goal is to control 2-3 home appliances wirelessly using an IoT dashboard. 

## Features
- Control 4 lights/appliances using a mobile/tablet app.
- Built using **ESP8266** and a **4-Channel Relay Module**.
- Integrated with **Blynk IoT Cloud** for wireless communication.

## Components Used
- ESP8266 (NodeMCU)
- 4-Channel Relay Module
- Connecting Wires & Bulb Holders
- Blynk Mobile App
